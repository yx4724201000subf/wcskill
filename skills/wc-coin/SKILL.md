# wc-coin：概念造词

学员版交付范围是候选词、换框句、自评和推荐。下文的“尺子／模拟反应测评”属于可选后续流程，本包未包含独立测评 Skill；没有该流程时，完成本轮交付并由用户选择，不调用未安装的工具。

## 一、为什么造词是命根(先读)

造词/重定义 = **占住语言** = 做教主(教师卖技能、可替代;教主装定义、粉丝用你的词思考)。它是整个内容系统的**承重梁**——全量数据证实:有造词的内容中位赞更高(4586>3652)、收藏不掉。一条内容的圆心,就是"你往观众脑子里装进了一个、只能用你的词去理解的新定义"。

本 skill 专做这最难、最承重的一下:**把一个"要被重定义的概念"造成一个 dbs 风格的好词。**

## 二、输入 / 输出

**输入**:一个**要被重定义的概念/真因**,外加一句"观众现在对它的默认理解是什么、错/糊在哪"。常常就是移植器留下的槽:`[待造词:命名『…』]`。

**输出**:
- **5 个候选词**,每个带:① 用了哪个套路 ② 一句"换框句"(把词放进句子里,展示它怎么用) ③ 好词尺自评(命中哪几条标准)。
- **推荐 1-2 个**(自评得分最高的)。
- 一句提醒:**终选走尺子**——把候选放进换框句/标题,过「模拟反应测评」(5 群角色扮演打分),留最高分的。本 skill 只负责生成+自评,不下最终结论。

## 三、dbs 造词的 10 个套路(从 452 实例提炼)

**主力两招(占大头,优先用):**
- **① 旧词重定义(204 个,最主力)**:拿人人挂嘴边、自带立场的现成词,不改字面,翻转它的判定标准或因果方向(褒→陷阱、原因→结果、资产→负债)。例:上班思维、私域是负债、稳定=精神鸦片。**威力最大、最像他,但最需要后面逻辑兜底。**
- **② 精确二分(69 个)**:沿一条"决定赚不赚钱/付不付钱"的轴,把一个糊词劈成对仗两半,给人一把自查刀。例:生产型/消费型兴趣、需求/诉求、引流款/利润款。**最稳、出场最高。**

**辅助 8 招(主力不顺时换):**
③ 比喻画面命名(紧箍咒/喂饭/门控) · ④ 借术语跨域(负杠杆/心理资本) · ⑤ 病症化确诊(求骗/模拟创业) · ⑥ 三分阶梯(告知/启发/植入) · ⑦ 拆字逼问(把"副业"拆成"副"和"业") · ⑧ 造度量(15%法则/钩子强度公式) · ⑨ 悖论并置(赚钱是在耽误我赚钱) · ⑩ 对仗格言(卖货卖的是货,IP 卖的是人)。

> 每招的"怎么做 / dbs实例 / 何时用",完整版见 `references/methodology.md`。

## 四、配方(给定一个概念 → 造词,8 步)

1. **锁圆心**:写下要被重定义的概念原话 + 一句"默认理解错/糊在哪"。错点 = 你要攻击的靶子。
2. **选轴劈二分**(套路②):问"这概念里,决定赚不赚钱/生死的那条线是什么?"沿它劈成对仗两半。劈不成跳第 3 步。
3. **找翻面处重定义**(套路①):问"大众默认它是好/原因/资产,我能不能证明它其实是坏/结果/负债?"能翻就同词翻面,翻面点就是钩子。
4. **配一个肉感画面**(套路③,**别空想,用第六节意象库逐个套**):问"这机制像生活里的什么东西?"画面要自带机制解释。
5. **(可选)装可量化旋钮**(套路⑧):能不能配一个阈值/公式/百分比,把"值不值得"从感觉变成账。
6. **一个内核造 5 个候选**:把前几步产物用不同句式包装——对仗成对 / 悖论并置 / 病症标签 / 对仗格言,凑够 5 个备选。
7. **过好词尺筛**(第五节):逐条打钩,选自评最高的 1-2 个。
8. **消歧 + 案例坐实**:预判别人会怎么杠这个词,逐词精确定义(这本身就是正文);再配一个具体到金额/品牌的案例让它立住(案例见红线:**可编、逻辑自洽即可**)。

## 五、好词尺(10 条,自评用)

秒懂(新但嫁接在熟悉画面/词根/梗上) · 可自查(听完能归类自己) · 自带立场会站队(不中性) · 反直觉但自洽(有硬逻辑兜底,不是抬杠) · 有承重性(能当圆心贯穿多条) · 有画面或痛感(脑子里看得见) · 可操作(自带动作/阈值) · 对仗成对更佳 · 是你立的框(别人引用=替你打广告) · 字少(2-6 字)。

## 六、意象库脚手架(第 4 步"配画面"专用——dbs 最吃天赋、最难复制的一步)

想不出画面时,拿这个概念**逐个意象库去套**,看哪个一套就通:
- **身体痛感**:紧箍咒 / 断电 / 漏电 / 嗓子冒烟 / 挠痒
- **赌桌江湖**:筹码 / 押注 / 黄牛 / 二道贩子 / 见路不走
- **电路机械**:杠杆(正/负)/ 加热(薯条)/ 空转 / 镜子
- **农业/喂养**:喂饭 / 韭菜 / 有机体衰老 / 养
- **家居空间**:空房间一把椅子 / 编一千个篮子 / 墙(体面墙)
- **金钱税费**:获客成本 / 隐性保险费 / X 税(磨刀税式)/ 洼地
- **修行/身份**:看山不是山 / 身份切换器 / NPC / 长衫

挑中后问:"看到这个画面,观众是不是立刻懂了为什么?"懂了才留。

## 七、坑(别造烂词)

✗ 太抽象没画面(系统性认知跃迁) ✗ 太学术掉书袋(本体论祛魅) ✗ 像营销黑话(赋能/闭环/抓手) ✗ 中性不带立场(无法站队) ✗ 二分两词不对仗(张力垮) ✗ 光反转没逻辑兜底(为炸而炸,反噬信任) ✗ 一次性俏皮话没承重 ✗ 新到没人懂(违背"新但秒懂") ✗ 字太多背不动 ✗ 抄对标的框/词(失去护城河、被当抄)。

## 八、红线

- **案例/数字可编、逻辑自洽即可**(亲历可编)。别因为"编不出真数字"就放弃一个反直觉好词——把数字编圆。
- **借用词别当你的原创承重梁**:反脆弱/科斯/交易成本/心理资本/负杠杆/2sigma 是 dbs 借来的(他自己都点名),不是他造的。你要造**自己立的框**;借术语只做调味,不做圆心。

## 九、终选走尺子(本 skill 之后的一步)

本 skill 只产"候选词 + 自评"。**最终选哪个,不靠自评,靠尺子**:把每个候选放进它的换框句/标题,过「模拟反应测评」——5 类目标人群(实操卖家/自媒体操盘手/高自尊准创业者/AI玩家/低粉高客单咨询型)各自角色扮演读它、给反应和分,留最高分、命中目标人群的那个。尺子是独立工序(多 agent 模拟,走 workflow)。
