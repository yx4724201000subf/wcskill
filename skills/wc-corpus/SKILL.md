# wc-corpus：语料纠错与气口断行

## 0. 产出目的与安全底线

短视频文案是「话套话」。本工序把每篇改排成**一行一拍**，让行尾的信息缺口与钩子可见。

**安全底线**：断行阶段只加换行、空行和 `◤◢` 标记行，不改、不删、不增正文。若输入是原始转写，先做谨慎内联清洗，后续的「拼回」基准改为清洗后正文。校验 100% 通过才算完成。

文件头必须声明：区间、段界与截停标注只是排版视图，不是拆解结论；后续文案分析必须重新阅读原文并独立判断。

## 1. 输入、排序与内联清洗

1. CSV 必须有正文列，建议有标题与赞数列。默认按赞数降序编号。
2. 用户明确指定篇数或比例时，严格按用户要求。用户未指定且超过 50 篇时，默认取高赞前 50。
3. 原始转写语料：仅修正可由上下文、标题、专名或固定表达明确反证的同音错字、品牌/人名/数字错误和无意义 ASR 噪音。绝不碰作者的口播指纹。
4. 已清洗语料：直接断行，不重复清洗。
5. 无法确定的字保留原样，记入「转写标点存疑」；确实发生的清洗改动记入文末附录，不另落 CSV/日志副产物。

## 2. 断行：一口气=一行=一拍

默认把 `。？！` 视为强边界，把 `，` 视为候选边界，标点留在行尾。逗号处是否真断，必须服从下方“功能原子链”规则，不能机械一逗号一拍。

五类不断：

1. 顿号连接的列举串及其收尾。
2. 被引用的示范文案/广告语：它是展品，不是话套话链。
3. 招式/要点报幕+短口诀（「第一招，我不完美。」）。
4. 排比短句串。
5. **功能原子链**：只有文本结构或音视频停顿能证明多个逗号分句本来就是同一口气、同一不可拆功能单元时，才保留成同一拍。不得仅因为下一拍出现大结果、碰撞或承诺，就事后并回首拍；前拍若已经承担强制对话、悬空、待解释对象或其他独立功能，按真实停顿分拍并各判各的。

另有一类必须先做**语气前导归属测试**：句首「我说真的／说实话／讲真的／老实说」等成分若只是在修饰紧随其后的核心判断，本身既没有独立召唤观众，也没有可单独回答的内容缺口，默认与核心判断合成同一拍；不能机械按逗号把语气前导切成第一拍，再把真正承担截停的判断推到第二拍。把它中性替换成「坦白讲／认真讲」后，如果观众仍只是等待同一个紧随判断，就证明它是修饰语而非独立悬空。只有音视频明确给出独立停顿，或前导本身已形成「问你个问题／你先听我说」这类强制对话，才单独成拍。该规则只修正首拍边界，不授权为了借用后拍的大结果而任意并句。

功能原子链优先于“短一点更像气口”，但证据不足时仍按逗号断拍，下一拍的功能不得倒借。典型不合并：「看完这期视频，／你将……」「冒昧地问一下，／具体问题……」「如果〔X〕，／那么〔Y〕」；这些前拍本身已经有独立功能。

含「能有什么/为什么/之所以/你有没有发现/凭什么/怎么回事/问题出在哪/你知道…吗」等悬念疑问词的短句必须单独成行。其余拿不准宁长勿短。

### ASR 停顿补断

即使原文无标点，也在以下位置补换行（不补标点）：

- **孤立主语**：人名/称谓/指代整拍单独立起，后面紧跟数据+动作。「我觉得 X 是对的」这类态度句不拆。
- **数据串**：同句连续出现 2 个及以上「数字+单位」数据块，每个数据块独立成拍。
- **无法一口气**：明显读不完的高密度陈述，按语义单元断。

## 3. 区间与段界

每篇使用三个标记：

- `◤开局｜截停：…◢`：净开仓，只挖坑不填坑。价值承诺、只立问题的错例也属开局。
- `◤交付◢`：从系统给答案/方法/演示的第一拍起。
- `◤收束◢`：从还完最后一笔、转向总结/号召/签名/互动的第一拍起。

只在交付区用空行标段界。一段=一个缺口从挖开到还完的完整循环。报幕句（第 X 招/步/点）优先做新段首行；亲手挖新缺口的转场句次之；口诀复读/原理句通常收段。拿不准宁大勿小，记存疑表。开局、收束内不加空行。

## 4. 截停标注：只看第一拍

第一拍=正文第一行。截停装置=信息流里让手指不由自主停下来的语言零件。**先判功能，后看语法**；不得用「句子完整」直接推出「无」。

### 4.1 首拍盲判、受众分支、逐词展开、复合登记与中性替换测试

- **先遮住第二拍以后，只读第一拍**，写出观众最自然的一句或几句追问，再选机制。相邻拍只能用于确认首拍属于对比前件、因果前件、展品或直接对话，不能把相邻拍的结果、成绩或价值倒灌成首拍的重量。
- 判断句再做**受众分支测试**：分别模拟观众暂时接受与拒绝这句话。拒绝时若自然追问「凭什么／你怎么知道」，检查预设。接受后追问「然后呢」只能作为悬空候选，还必须有首拍内尚未落下的条件／因果／转折／比较关系，或由相邻拍明确证明首拍已启动该关系前件（如「我知道你不是天才，／但……」）；“作者显然还会继续讲”或“观众还想听解释”本身不算悬空，否则任何完整观点都会被误标。不能预先假定所有观众都会接受作者框架，也不能见判断句就强行凑齐两支；只有两条反应都能形成独立、具体且通过结构证据门槛的截停心理时才复合登记。
- 再做**逐词展开测试**：按真实听觉顺序，从左到右检查词、词组、分句和整拍。某个局部在被听到的当下已经独立打开缺口，即使后面的同拍文字把这个微缺口补上，也要登记；整拍结束后仍留下的下一层缺口另行登记。例如「为了做好」先让人问「做好什么」，听完「为了做好这个短视频，」又让人问「为了做好它，你做了什么」。两问发生在不同展开层级，均属有效截停。局部必须落在自然听觉／语义节点，并形成可说出的不同追问；禁止任意截取字符前缀，把所有尚未读完的短语机械膨胀成悬空。
- 同一首拍可同时命中多个机制；不再只标「主机制」。
- 对每个候选词/词组/句式做**中性替换测试**：用不破坏周边语法、但移除该候选功能的普通表达替换它，再比较截停心理是否消失。不要直接删除必要句法成分，否则会把删坏句子造成的不完整误算成该词的截停力。测试结构性悬空时，替代项必须改成自足表达，不能换成另一个同样缺宾语／后件的结构来复制原缺口。替换后若观众仍在同一展开时点追问同一个问题，该候选只是内容填充物，不独立登记。
- 同一语言零件不重复登记。只有它同时通过两条独立心理通路时，才允许复合机制；同一机制也可登记多个**不同展开层级、不同具体追问**的嵌套载体，统一按“整拍／整句在前，局部词组在后”排列。若只是用长短两种说法重复同一个缺口，则合并。同一机制还可有多个并列证据，例如「超过8000人」、「付过费」、「来找我解答商业类问题」都独立增加已有证据的重量，可分别登记为预设价值的载体；不需要另造「社会证明/专业定位」机制。
- **先校正语气前导，再做首拍盲判**：若第一行只是「我说真的，」而下一行才是它所修饰的核心判断，先按第 2 节的语气前导归属测试重新合拍，再判断预设、矛盾等功能；不得把语气修饰语判成「无」后就停止，也不得把「说什么」当成独立悬空。
- 只能使用本节的 7 种机制与 5 种载体。禁止临时发明「主观封神/专业定位/新奇概念/时间锚点/社会证明」等新手法名。

### 4.2 机制轴：为什么停

1. **强制对话**：首拍直接把当前观众叫进一次对话、测试、回答、选择、猜测、打赌、看/听或共同讨论场景（「你好朋友」「喂喂喂」「来做个测试」「问你个问题」「先给你看两个文案」「今天我们来讲〔X〕」）。它依靠参与压力，不得再按旧规则判成「流程报幕=无」。只是在转述别人说话、展示广告/歌词，或纯栏目题头/站次通报，不算直接把当前观众叫进来。
2. **悬空**：词组、分句或整拍由明确关系词或结构启动了一条尚未落下后件的信息关系（「因为〔X〕，」「如果〔X〕，」「为了〔X〕，」、只给出一端的对比前件）。逐词展开中，局部可先缺宾语或对象（如「为了做好」→「做好什么」）；同拍补上对象后，完整目的分句仍可缺动作或结果（如「为了做好这个短视频，」→「你做了什么」），两层问题可分别登记。局部语法能成立，也可能被相邻拍证明是成对比较/因果结构中尚未落下另一端的前件；但逗号、没有谓语或后文还有内容都不足以单独证明悬空，必须指出每个载体具体缺的是哪一个对象、因果、条件、转折、动作或比较后件。
3. **预设**：拍内存在未落点指称、待解释的身份/里程碑/异常状态、被先当成共识的争议因果/结论，或强迫观众认领的行为与认知框架（「这是你的〔X〕」「你可能想不到〔X〕」「你应该听过〔X〕」「我们中国有句话叫〔X〕」「所有人都知道〔X〕」「最重要的一件事就是〔X〕」「你每天都在〔X〕」「今天是我做〔X〕的第105天」「我好像迷失在〔X〕」）。还包括**待解释对象**：第一拍特意把一个店、人、物或事件指给观众看，或用完整名词短语把它立成话题，先把它设成“值得注意”，却暂不说明为什么；观众自然追问「这个〔对象〕怎么了／为什么特意提它」。这种相关性缺口不因句法完整或缺少谓语而改变：若观众追的是对象意义，仍归预设，不因逗号或名词短语形态机械归悬空。把未落定归属/主体的关系身份直接摆成对象（如「这是一个老婆」）也属预设；有明确归属和姓名、后续也只是普通介绍的「这是我的小学同学王某」则是普通介绍。评价词只有在它承担首拍钩子、证据被刻意延后时才算预设（如先说「一条很魔性的广告」，下一拍才交代魔性在哪）；普通修饰语和普通事实陈述不自动等于预设。必须写出观众被迫补的具体问题。判断重点不是后文还会不会讲，而是首拍是否已把一个尚未证明的框架、身份意义、评价、异常状态或对象相关性塞给观众。
   - **劝告整句与术语局部可双层登记**：首拍「不建议你／大家去做〔X〕」先把“〔X〕不值得做”作为尚未证明的判断塞给观众，整句预设回答「凭什么不建议」；若〔X〕本身又是尚未解释的命名（如「工具人博主」），局部预设回答「什么是〔X〕」。两问不同且分别通过中性替换测试时，按整句在前、局部在后同时登记；不得只留下术语，漏掉整句判断。若劝告还直接把当前观众拉进一次行动选择，可另并列强制对话；不能因为出现「大家」就机械命中，必须确认它确实指向当前观众的选择。
4. **矛盾**：拍内成分语义打架、标签碰撞或角色/栏目预期被反转（「你的〔X〕是一个〔Y〕」「月薪3000的00后干翻CEO」「眼前的这个男人正在吃饭」「文案号今天不写文案」）。栏目/人物角色预期可以来自该篇标题、固定账号身份或画面中首拍正在指认的对象，但标记载体仍须能在首拍落地；大结果不自动等于矛盾，必须指出具体的碰撞双方。
5. **发问**：疑问词/疑问句把具体内容缺口直接说出口（如何/为什么/怎么/凭什么/…吗）。「问你个问题」若未在同拍问出具体内容，只标强制对话；同拍出现「如何」等具体缺口时，两者可复合。
6. **预设价值**：首拍把**已经落地、只看本拍就能衡量**的证据或重量压给观众；这里的“价值”是信息重量，不等于正向成绩。包括极端数值/巨额/反常时长或年龄/高身份证据/付费事实（「19800，」「超过8000人付过费」「至少五位A9」「我想象我写文案能写到89岁」）。低层级、小规模、短起步只有在**同拍也落下参照、结果或明确成就关系**，使观众当场看见「这么小／这么短却做到这么大」时，才能作为重量登记；单独为下一拍结果铺垫的地点、规模、时长不是预设价值。例如「一个注册十天的新号，只发两条视频就涨粉一万」可登记拍内的小起点与大结果；「十八线县城的一家小店，」或「一个刚注册十天的新号，」不能借后文的90万／1万粉变成预设价值。普通日期、普通序号、普通地点和任意数字不算重物。
7. **价值承诺**：首拍承诺观众将获得或避免的具体价值，包括能力承诺（学会识别/控制/说服）、效果承诺（让表达/决策更好）、改变承诺（变聪明/摆脱问题）和结果承诺（在〔时间〕内靠〔小起点〕做到〔大结果〕）。「今天我们来讲控制大脑/掌控情绪」即使没有「如何」，只要动作词本身明确指向观众可获得的能力，也应登记价值承诺；「今天讲经济学/某本书」这类主题报幕没有具体能力、改变或效果，不算。标记统一写「价值承诺」，不把四个子类另造成新机制名。

### 4.3 载体轴：登记什么

只允许以下 5 种载体：

- **词**：单个固定词（「如何」）。
- **词组**：不带可替换槽位的固定短语（「超过8000人付过费」）。
- **带槽句式**：句子／分句级载体。默认原样登记第一拍中起作用的完整表层句式（如「为了做好这个短视频，」）；需要沉淀可复用模板时，可把**纯内容填充物**替换为 `〔X〕`，但不得槽掉「做好／不是／只要／竟然」等正在制造功能的词。为兼容既有五载体命名，完整表层句式即使暂不抽槽，也仍记作“带槽句式”。
- **标签对**：拍内两个可指认且语义相撞的标签（「月薪3000×干翻CEO」）。
- **孤立主语**：人名/称谓/指代整拍单独立起，后拍才接数据+动作，归入预设。主语与谓语在同拍时不算孤立主语。

### 4.4 冲突与复合判定

- **强制对话 vs 发问**：前者是参与压力，后者是具体内容缺口；同拍各自成立时并列。
- **发问 vs 价值承诺**：「如何」挖方法缺口，「控制别人的行为」承诺能力；两条通路独立，可并列。
- **预设价值 vs 价值承诺**：前者是已有证据/重量，后者是观众将获得的价值；不得因为都有价值感而混标。
- **矛盾 vs 价值承诺**：语义碰撞与大结果不是一回事；没有拍内对撞就不标矛盾。
- **悬空 vs 其他机制**：悬空只看拍内语义是否闭环，不看行尾标点；其他零件能独立通过中性替换测试时可并列。
- **悬空 vs 预设**：不要按“有没有谓语”分。由因为／如果／为了／对比前件等关系明确索取后件，观众问「条件成立后怎样／原因导向什么／另一端是什么」，走悬空；一个对象被指认或立成话题，观众问「它怎么了／为什么提它」，走预设。完整名词短语即使没有谓语，只要追问指向对象意义，也归预设。同一整拍若确实产生「接受这个判断后，然后呢」与「凭什么这样判断」两条独立心理路径，可分别登记悬空与预设；不能把同一个「这个对象怎么了」重复登记为两种机制。
- **预设 vs 普通陈述**：必须写出「观众被迫补什么」；只是后文还会继续讲，不等于预设。
- **强制对话 vs 预设**：称呼、召唤、命令观众参与，走强制对话；把某种行为/认知先套到观众身上，走预设。两者不能因都出现「你」就混标；只有两条功能同时独立成立才并列。
- **预设 vs 预设价值**：先看观众的追问。问「这个对象怎么了／为什么值得说」是预设；本拍已经让人感到「竟然这么多／这么久／这么大」才是预设价值。后文揭晓后才显得厉害的低起点，仍不是首拍的预设价值。确有两条独立心理通路且分别通过中性替换测试时才并列。
- **预设 vs 矛盾**：未解释、未证明不等于语义相撞。能写出具体碰撞双方才标矛盾；否则即使很反常，也只按预设或预设价值处理。

### 4.5 标记格式与判「无」

- 复合：`◤开局｜截停：强制对话·带槽句式「今天我们来讲〔X〕」＋发问·词「如何」＋价值承诺·带槽句式「用〔你的语言〕控制〔别人的行为〕」◢`
- 单项：`◤开局｜截停：发问·词「为什么」◢`
- 确无：`◤开局｜截停：无◢`

正文第一行已经是权威首拍。每个词/词组必须能在首拍原文中找到；带槽句式若原样登记必须能在首拍中逐字找到，若含槽则必须能用首拍填回，且不得槽掉承担功能的词；标签对两端必须都在首拍；孤立主语必须等于首拍主体。

7 种机制全部不成立才标「无」。纯栏目题头、纯展品/广告语/歌词、完整自足且不制造参与压力/缺口/碰撞/重量/承诺的陈述，可判无。标无不等于画面没截停；画面层可能性记存疑表。

### 4.6 判定纪律

1. 先做首拍盲判、受众分支与逐词展开测试，再查看相邻拍确认第一拍的语法/语义边界和言语归属（例如它是对比前件、作者直接对观众说，还是作者展示的广告语/歌词）。相邻拍不得改变首拍已有的信息量，不得把相邻拍才出现的结果、重量、机制或承诺借给第一拍。
2. 对每个词、词组、分句和整拍候选分别写出观众在该展开时点脑中的具体问题；写不出就不标。
3. 对每个复合项做中性替换测试；同义重复或在同一展开时点只触发同一个追问就合并，不同展开层级产生不同追问则保留。
4. 强弱是另一维度，不参与有无判定。拿不准的记存疑表，别硬拍。

### 4.7 已裁决边界与回归测试

以下是已经确认过的边界。后续全量审计必须先通过这些回归测试，不能再用「完整陈述」「流程报幕」把它们判回「无」：

| 首拍或结构 | 至少应命中 | 不应误判为 |
|---|---|---|
| `今天有两个问题` / `来做两个测试` / `首先问你一个问题` | 强制对话 | 无、流程报幕 |
| `今天我们来分享一些经济学的原理` | 强制对话 | 无、栏目题头 |
| `今天我们来讲如何用你的语言来控制别人的行为` | 强制对话＋发问＋价值承诺 | 只标强制对话、只标发问 |
| `你可能想不到〔X〕` / `你应该听过〔X〕` | 预设 | 无、普通陈述 |
| `我们中国有句话叫做七岁看老` | 预设 | 无、单纯引用俗语 |
| `你好朋友` / 作者直接对当前观众说的 `喂喂喂` | 强制对话 | 无、语气词 |
| `你有没有发现，` / `有没有想过，`，宾语留到下一拍 | 强制对话＋悬空 | 只标强制对话、误加发问 |
| `你每天都在刷牙` | 预设 | 无、普通事实 |
| `我是个文案` 独立成拍，后拍才接反常数据或动作 | 预设·孤立主语 | 无、自我介绍展品 |
| `今天是我做短视频的第105天`，该里程碑意义待解释 | 预设 | 无、普通日期 |
| `我好像有一点点迷失在城乡结合部了` | 预设 | 无、完整状态句 |
| `我想象我写文案能写到89岁` | 预设价值 | 无、普通愿望 |
| `这是一个老婆`，关系归属和主体均未落定 | 预设 | 无、普通物品展示 |
| `这家叫〔X〕的羊肉粉店`，作为完整名词短语单独立起 | 预设；追问「这家店怎么了」 | 因无谓语机械判悬空、无 |
| 文案账号首拍 `今天就不写文案了` | 矛盾 | 无、完整决定 |
| `眼前的这个男人正在吃饭`，画面/标题把它作为异常对象指认 | 矛盾 | 无、普通动作陈述 |
| `所有人都知道〔X〕，最重要的一件事就是〔Y〕` | 预设；两个单位均通过中性替换测试时分别登记 | 无、完整结论 |
| `今天我们来讲控制大脑` / `今天我们来讲掌控情绪` | 强制对话＋价值承诺 | 只标强制对话 |
| 第一拍 `这是一盘景区小炒肉`，下一拍才给出与之成对的另一盘 | 预设；追问「为什么特意给我看这盘菜／这盘菜怎么了」 | 因句法完整判无、因后文有比较机械判悬空 |
| 第一拍 `这栋黑房子是我开的文案工作室，`，后拍才说明工作一周赚到年薪 | 预设·带槽句式「这栋黑房子是我开的文案工作室，」；追问「这个工作室怎么了」 | 无、借后拍收入判预设价值 |
| 第一拍 `这是我老家十八线县城的一家牛肉粉小店，`，后拍才出现两个服务员和90万利润 | 预设·带槽句式「这是我老家十八线县城的一家牛肉粉小店，」；追问「这家小店怎么了」 | 预设价值、悬空、无；不得借后拍90万给首拍增重 |
| 第一拍 `一个刚注册十天的新号，`，后拍才出现两条视频和1万人关注 | 预设·带槽句式「一个刚注册十天的新号，」；追问「这个新号怎么了」 | 因无谓语判悬空、预设价值；不得借后拍1万粉给「十天」增重 |
| 第一拍 `一个注册十天的新号，只发两条视频就涨粉一万` | 预设价值；小起点与大结果均在本拍落地，可分别做中性替换测试 | 只因出现「十天」就机械命中 |
| 第一拍 `我知道你不是天才，`，后拍以「但」转折 | 预设·带槽句式「我知道你不是天才」＋悬空·带槽句式「我知道你不是天才，」；分别追问「凭什么这么说」与「接受后，然后呢」 | 把功能词槽成过宽的「我知道〔X〕」、只留一种心理结果 |
| 第一拍 `为了做好这个短视频，` | 悬空·带槽句式「为了做好这个短视频，」＋悬空·词组「为了做好」；分别追问「你做了什么」与逐词展开时的「做好什么」 | 只记抽象的「为了〔X〕，」、把两个展开层级合并 |
| `我说真的，文艺逼才是自媒体的版本答案。`；「我说真的，」只修饰后句 | 先合为同一首拍，再判预设·带槽句式「文艺逼才是自媒体的版本答案。」＋矛盾·标签对「文艺逼×自媒体的版本答案」 | 把「我说真的，」机械切成首拍后判无或悬空、把核心判断推到第二拍 |
| `真的不建议大家现在还去做那种工具人博主啊。` | 强制对话·带槽句式「真的不建议大家现在还去做那种工具人博主啊。」＋预设·带槽句式「真的不建议大家现在还去做那种工具人博主啊。」＋预设·词组「工具人博主」；分别追问「我还做不做／凭什么不建议／什么是工具人博主」 | 只标强制对话、只标术语预设、漏掉整句争议判断 |
| 被展示的广告语、歌词、纯系列题头 | 无 | 把展品中的命令或疑问借给作者 |

回归样例只锁定功能边界，不授权照词匹配。相似句仍须通过首拍盲判、受众分支、逐词展开、中性替换测试、拍内落地和冲突规则；不得因为出现「今天」「你」「数字」就机械命中。

## 5. 产出文件

文件名：`{作者}·气口断行版.md`。唯一产出就是该 Markdown，不另落清洗 CSV、日志或其他副产物。

结构：

1. 文件头：这是什么、断行规则、区间/段界规则、截停 7 机制×5载体+复合登记+首拍盲判/受众分支/逐词展开/中性替换测试、使用铁律、免责声明、存疑说明。
2. 正文 N 篇：`## 篇 N｜标题｜赞 X` + 三个区间标记 + 断行正文。N 以用户指定或选样规则为准。
3. 「转写标点存疑（待裁决）」表：篇号|原文片段|疑点。
4. 「段界/区间/截停存疑（待裁决）」表：篇号|位置|本次判法+另一可能。
5. 若走过内联清洗，加「附录·清洗改动清单」：篇号|原文片段|改后|依据。

## 6. 机械校验（必做）

1. 逐篇剔除 `◤` 开头标记行和空行，拼接所有正文行；必须逐字等于清洗后正文/源文。
2. 每篇恰有 1 个开局、1 个交付、1 个收束标记。
3. 开局标记只使用下列白名单：
   - 机制：强制对话|悬空|预设|矛盾|发问|预设价值|价值承诺
   - 载体：词|词组|带槽句式|标签对|孤立主语
4. 标记不得出现旧字段 `截停机制：` / `功能零件：` / `首拍「…」`，不得出现方法论外标签或重复项。
5. 词/词组与标签对两端可追溯到正文第一行；带槽句式原样登记时逐字可追溯，含槽时可用第一拍填回且未槽掉功能词；孤立主语符合整拍孤立条件。
6. 无 U+FFFD 等损坏字符。
7. 汇报：N/N 拼回|各机制命中数|复合/单项/无计数|交付平均段数|两张存疑表条数。

## 7. 执行策略

- 全量断行+标注是大读写任务，可交给 subagent 执行，主会话必须读取本 skill、独立抽查与运行校验。
- 首次处理新作者且用户尚未确认断句/标注手感时，先试做 1 篇；已有用户确认的同格式基准时可直接全量。
- 机械校验通过不等于内容判定正确。完成后额外抽查高赞头部、选样边界篇、末篇、判「无」的全部篇目与复合机制高频篇。
